# Contributing to Cell Simulation Diffusion Model

Thank you for your interest in contributing!

## Development Setup

1. Clone the repository
2. Create a conda environment:
   ```bash
   conda create -n cell_simul_env python=3.10
   conda activate cell_simul_env
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Code Style

- Follow PEP 8 guidelines
- Use type hints where appropriate
- Document functions with docstrings
- Keep functions focused and modular

## Testing

Before submitting changes:
1. Test preprocessing pipeline
2. Verify model forward pass
3. Run training for a few epochs
4. Check that visualizations are generated

## Pull Request Process

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Ensure code is well-documented
5. Submit a pull request with clear description

## Questions?

Open an issue for discussion.
